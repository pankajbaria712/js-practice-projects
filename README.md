## 📖 About

This repository contains all my **JavaScript practice projects** created during my learning journey at **Sherians Coding School**.  
Each folder includes a mini project demonstrating a JavaScript concept such as DOM manipulation, localStorage, or filtering logic.

🎯 **Goal:** Improve JavaScript skills by building small, useful, and visually attractive projects.

## 🧭 How to Add a New Project

1. Create a new folder → `04.Project-Name/`  
2. Add:
```

index.html
style.css / style.scss
script.js

````
3. Update your `index.html` (dashboard) to include the new project:
```html
<a href="04.Project-Name/" class="card">
  <h2>🧠 Project Title</h2>
  <p>Short project description.</p>
</a>
````

4. Commit & push — it’ll appear automatically on your GitHub Pages site 🎉
